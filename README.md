# Barbara_portfolio

## Overview
Welcome to my portfolio!  
This project showcases my skills, projects, and experience.  
The project is divided in 4 sections :
- Home : Small presentation and sandbox page
- About : Discover me through my tech journey
- Skill : List of my actual skills in tech
- Project : List of projects I made personnally or with a group, categorized by 42 or personnal projects

## Features
- Language : English - French
- Theme mode : Light - Dark

## Tech Stack
- React with Typescript for the frontend
- TailwindCSS for styling
